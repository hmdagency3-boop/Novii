## 🧠 تفاصيل الخوارزمية

### نموذج الحساب (Scoring Model)

الخوارزمية تحسب درجة توصية لكل مستخدم بناءً على 4 عوامل موزونة:

#### **العامل 1️⃣: المتابعون المشتركون (40%)**
```
الوزن: 40%
الصيغة: mutual_count × 100 × 0.40
المنطق: الأشخاص مع أصدقاء مشتركين أكثر احتمالاً للاهتمام بالمتابعة
مثال: إذا كان لديك 10 أصدقاء مشتركين = 10 × 100 × 0.40 = 400 نقطة
```

#### **العامل 2️⃣: عدد المتابعين (30%)**
```
الوزن: 30%
الصيغة: LOG(followers_count + 1) × 50 × 0.30
المنطق: حساب لوغاريتمي للشهرة (يمنع هيمنة الحسابات الكبيرة)
مثال: حساب بـ 1000 متابع = LOG(1001) × 50 × 0.30 ≈ 69 نقطة
```

#### **العامل 3️⃣: حالة التحقق والبدجات (15%)**
```
الوزن: 15%
الدرجات:
  ✅ is_verified (موثق): 50 نقطة
  🏛️ is_official (رسمي): 40 نقطة
  🎬 is_creator (منشئ محتوى): 30 نقطة
  ⭐ is_premium (بريميوم): 20 نقطة
الصيغة: badge_score × 0.15
المنطق: الحسابات الموثوقة والمعروفة لها أولوية
```

#### **العامل 4️⃣: النشاط الأخير (15%)**
```
الوزن: 15%
الدرجات:
  🔥 آخر 7 أيام: 50 نقطة
  📅 آخر 30 يوم: 30 نقطة
  ⏰ أقدم من ذلك: 10 نقاط
الصيغة: recency_score × 0.15
المنطق: الحسابات النشطة مؤخراً أكثر قيمة
```

### الصيغة النهائية (Final Score)

```
┌─────────────────────────────────────────────┐
│  Final Score =                              │
│                                             │
│  (mutual_count × 100 × 0.40) +              │  40% - المشترك
│  (LOG(followers_count + 1) × 50 × 0.30) +   │  30% - الشهرة
│  (badge_score × 0.15) +                     │  15% - الموثوقية
│  (recency_score × 0.15)                     │  15% - الحداثة
│                                             │
│  Total = 100%                               │
└─────────────────────────────────────────────┘
```

**المعاملات:**

**معاملات الإخراج (Response):**

```json
      "username": "john_doe",
      "full_name": "John Doe",
```

**استعلام SQL المستخدم (SQL Query):**

```sql
WITH user_followers AS (
  -- الخطوة 1: جمع جميع الأشخاص الذين يتابعهم المستخدم الحالي
  SELECT following_id 
  FROM follows 
  WHERE follower_id = $1
),
mutual_followers AS (
  -- الخطوة 2: حساب عدد المتابعين المشتركين لكل مستخدم مقترح
  SELECT 
    uf.id,
    COUNT(DISTINCT f.follower_id) as mutual_count
  FROM profiles uf
  LEFT JOIN follows f ON f.following_id = uf.id 
    AND f.follower_id IN (SELECT following_id FROM user_followers)
  WHERE uf.id != $1
    AND uf.id NOT IN (SELECT following_id FROM user_followers)
    AND uf.is_banned = false
  GROUP BY uf.id
),
scored_users AS (
  -- الخطوة 3: حساب درجة التوصية لكل مستخدم مرشح
  SELECT 
    p.id,
    p.username,
    p.full_name,
    p.avatar_url,
    p.bio,
    p.followers_count,
    p.is_verified,
    p.is_official,
    p.is_creator,
    p.is_premium,
    p.is_active,
    p.updated_at,
    COALESCE(mf.mutual_count, 0) as mutual_followers_count,
    -- حساب درجة التوصية بناءً على الأربع عوامل
    (
      -- العامل 1: المتابعون المشتركون (40%)
      (COALESCE(mf.mutual_count, 0) * 100) * 0.40 +
      -- العامل 2: عدد المتابعين (30%)
      (LOG(p.followers_count + 1) * 50) * 0.30 +
      -- العامل 3: التحقق والبدجات (15%)
      (CASE 
        WHEN p.is_verified THEN 50
        WHEN p.is_official THEN 40
        WHEN p.is_creator THEN 30
        WHEN p.is_premium THEN 20
        ELSE 0
      END) * 0.15 +
      -- العامل 4: النشاط الأخير (15%)
      (CASE 
        WHEN p.updated_at > NOW() - INTERVAL '7 days' THEN 50
        WHEN p.updated_at > NOW() - INTERVAL '30 days' THEN 30
        ELSE 10
      END) * 0.15
    ) as recommendation_score
  FROM profiles p
  LEFT JOIN mutual_followers mf ON p.id = mf.id
  WHERE p.id != $1
    AND p.id NOT IN (SELECT following_id FROM user_followers)
    AND p.is_banned = false
)
-- الخطوة 4: اختيار النتائج وترتيبها
SELECT 
  id,
  username,
  full_name,
  avatar_url,
  bio,
  followers_count,
  is_verified,
  is_official,
  is_creator,
  is_premium,
  is_active,
  mutual_followers_count,
  recommendation_score
FROM scored_users
ORDER BY recommendation_score DESC
LIMIT $2;
```

**شرح استعلام SQL:**

1. **CTE `user_followers`**: جلب قائمة بجميع الأشخاص الذين يتابعهم المستخدم الحالي
2. **CTE `mutual_followers`**: حساب عدد المتابعين المشتركين بكفاءة عالية
3. **CTE `scored_users`**: حساب درجة التوصية لكل مستخدم باستخدام الأربع عوامل
4. **SELECT النهائي**: ترتيب النتائج وإرجاعها مرتبة تنازلياً

```typescript
async getSuggestedUsers(limit = 50): Promise<Profile[]> {
  const { data: { user } } = await supabase.auth.getUser();
  if (!user) return [];

  try {
    // استدعاء الـ endpoint الجديد
    const response = await fetch('/api/suggestions/recommended', {

      },

      throw new Error('Failed to fetch recommendations');
    }

    const { data } = await response.json();
    return data || [];
  } catch (error) {
    console.error('Error fetching recommendations:', error);
    return [];
  }
}
```

```
┌────────────────────────┬──────────┬─────────────────────┐
```
